## 2. Definition of Ready (DoR) & Definition of Done (DoD)

### Definition of Ready (DoR):
* User story follows standard structure: *As a [Role], I want [Capability], So that [Business Value]*.
* Acceptance criteria defined in executable Gherkin format (*Given-When-Then*).
* UI wireframes / UX flows attached and reviewed by design lead.
* Dependencies identified and confirmed non-blocking.
* Estimated in story points by cross-functional team.
* Business value and priority (MoSCoW) clearly designated.

### Definition of Done (DoD):
* All acceptance criteria verified and passed via automated/manual tests.
* Unit test coverage $\ge$ 85% for business logic and validation algorithms.
* Static code analysis passes with zero critical/high security vulnerabilities.
* End-to-end integration tests pass in staging environment.
* Peer code review completed and approved by two senior engineers.
* Operational documentation, user guides, and API specs updated.
* UAT sign-off received from business product owner and compliance delegate.
